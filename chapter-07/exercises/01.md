**Q**: On an Intel x86 system under Linux, if we execute the program that prints
"hello, world" and do not call exit or return, the termination status of the
program - which we can examine with the shell is 13. Why?

---

**A**: on an Intel x86 under Linux, when a called function is expected to return an
integer, the caller function expects the callee to store this value in the `eax`
register. `printf` returns the number of printed characters, in this case it
will return 13, meaning that it will set `eax` value to 13. Since the `eax`
register is not modified by main routine, this value is subsequently read by the
setup function, which terminates the program with the value found in that
register.
