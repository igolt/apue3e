**Q**: At the end of Section 7.10, we showed how a function can’t return a
pointer to an automatic variable. Is the following code correct?
```c
int f1(int val) {
  int num = 0;
  int *ptr = &num;

  if (val == 0) {
    int val;

    val = 5;
    ptr = &val;
  }
  return (*ptr + 1);
}
```

---

**A**: The code is correct. `ptr` either points to `num` or it points to `val`
that is declared inside the `if` statement. Even though the `val`
variable declared in the `if` is out of scope when the function value is
returned it's memory is still valid and contains the value defined inside
the `if` statement.
