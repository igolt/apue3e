**Q**: Calculate the latest time that can be represented by the `time_t` data
type. After it wraps around, what happens?

---

**A**: The maximum value `time_t` can represent depends on the defined type by
the system. Most systems defines `time_t` to be a signed 64 bits integer. In
this case the value is wrapped around and it's equal to the minimum
representable value of that type.
