**Q**: In Section 4.12, we said that a file size of 0 is valid for a regular
file. We also said that the st_size field is defined for directories and
symbolic links. Should we ever see a file size of 0 for a directory or a
symbolic link?

---

**A**: The file size will never be 0 for a directory or a symbolic link. The
file size of a directory will be a multiple of some number, and since
directories always contains information about it's entries and a directory will
have at least two entries, there is no way for it's size to be zero. For a
symbolic link, it's size is the size of the file path that it points to, and
since an empty string is not a valid path, there is no way for it's size to be
zero.
