**Q**: Each process also has a root directory that is used for resolution of
absolute pathnames. This root directory can be changed with the chroot function.
Look up the description for this function in your manuals. When might this
function be useful?

---

**A**: `chroot` might be useful when we want to restrict our process from opening
files outside a given directory. It should not be used by any kind of security
purpose, since it's still possible to bypass the restriction and access files
outside the `chroot` directory tree. As an example, the following code shows how
we can still access the file `outsidechroot`. We spawn a child process that will
chroot into `new-root`, `chdir` into `mydir`. The parent process will move out
`mydir` from `new-root`, using `rename`. In that point, the child process can
access `outsidechroot` file using the path `../outsidechroot`. The program below
needs to be executed as root, since `chroot` requires root privileges.
