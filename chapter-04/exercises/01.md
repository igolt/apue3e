**Q**: Modify the program in Figure 4.3 to use `stat` instead of `lstat`. What
changes if one of the command-line arguments is a symbolic link?

---

**A**: If we use the `stat` function instead of `lstat` would end up
not counting the symbolic links in the file system, because `stat` retrieves
information about the file the symbolic link points to, rather than about the link
itself.
