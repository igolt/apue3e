**Q**: Note in the output from the ls command in Section 4.12 that the files
core and core.copy have different access permissions. If the umask value didn’t
change between the creation of the two files, explain how the difference could
have occurred.

---

**A**: The files were simply created with different modes. From Figure 3.2 we
can see that the `core` file was created with `FILE_MODE`, which has the value
`S_IRUSR | S_IWUSR | S_IRGRP | S_IROTH`. core.copy was created as a result of
a redirection, which causes the shell to create the core.copy file.
