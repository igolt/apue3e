**Q**: Examine the archive formats used by the `cpio(1)` and `tar(1)` commands.
(These descriptions are usually found in Section 5 of the UNIX Programmer ’s
Manual.) How many of the three possible time values are saved for each file?
When a file is restored, what value do you think the access time is set to, and
why?

---

**A**: `cpio` and `tar` only saves the `mtime` field for each file. When a file
is restored, if the file does not exists, the access time is set to the current
time. If the file exists, the access time is not modified.
