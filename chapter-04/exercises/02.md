**Q**: What happens if the file mode creation mask is set to 777 (octal)? Verify
the results using your shell’s `umask` command.

---

**A**:
```bash
$ uname -srvo # Print information about the Kernel and Linux distribution
Linux 6.17.0-22-generic #22~24.04.1-Ubuntu SMP PREEMPT_DYNAMIC Thu Mar 26 15:25:54 UTC 2 GNU/Linux
$ cat foo # Just to show that the file doesn't exists
cat: foo: No such file or directory
$ umask 777
$ touch foo
$ ls -l foo
---------- 1 igolt igolt 0 Apr 23 16:52 foo
$ cat bar # Just to show that the file doesn't exists
cat: bar: No such file or directory
$ umask 002
$ touch bar
$ ls -l bar
-rw-rw-r-- 1 igolt igolt 0 Apr 23 16:52 bar
```
As we can see from the output of the commands above, if the file creation mask
is set to 777 octal new files are created with all the permission bits turned
off.
