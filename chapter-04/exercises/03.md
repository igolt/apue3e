**Q**: Verify that turning off user-read permission for a file that you own denies your access to
the file.

---

**A**:
```bash
$ uname -srvo # Print information about the Kernel and Linux distribution
Linux 6.17.0-22-generic #22~24.04.1-Ubuntu SMP PREEMPT_DYNAMIC Thu Mar 26 15:25:54 UTC 2 GNU/Linux
$ echo "bar" > foo
$ ls -l foo
-rw-rw-r-- 1 igolt igolt 4 Apr 24 09:30 foo
$ chmod u-r foo # turn off user-read permission
$ ls -l foo
--w-rw-r-- 1 igolt igolt 4 Apr 24 09:30 foo
$ cat foo # this should fail as we don't have permission to read
cat: foo: Permission denied
$ echo "baz" >> foo # we still have permission to write
$ ls -l foo # verify if the file size increased
--w-rw-r-- 1 igolt igolt 8 Apr 24 09:30 foo
$ chmod u+r foo # turn on user-read permission
$ cat foo # now we should be able to read the file contents
bar
baz
```
Turning off user-read permission for the file does not completely deny my access
to the file as we can see from the execution of the commands above. Turning off
user-read permission only denies the access to read the contents of the file,
but it is still possible to write and turn on the user-read permission again.
