**Q**: In Figure 4.20, we show the `unlink` function as modifying the
changed-status time of the file itself. How can this happen?

---

**A**: Unlinking a file doesn't mean that we are freeing the file system space
it's using, we are just removing a link to the file. The file system space is
only freed when the link count reaches 0 and no processes have the file open.
