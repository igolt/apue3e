**Q**: Type in the program that copies a file using line-at-a-time I/O (`fgets`
and `fputs`) from Figure 5.5, but use a `MAXLINE` of 4. What happens if you copy
lines that exceed this length? Explain what is happening.

---

**A**: If there are lines in the input file that exceed the `buf` capacity it
simply stop reading after filling `buf`. `fgets` will read until it fills the
`buf` (considering the null character) or until it finds a newline character
(`\n`);
