**Q**: The following code works correctly on some machines, but not on others.
What could be the problem?

```c
#include <stdio.h>

int
main(void)
{
  char c;

  while ((c = getchar()) != EOF)
    putchar(c);
}
```

---

**A**: On some machines `char` may be synonymous with `unsigned char`. As `EOF`
is normally defined as `-1` integer, when converting `-1` integer to `unsigned
char` there is a loss of information about the signal. When trying to compare
with the value of `EOF` the comparison will always result in `false`.
